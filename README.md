# Tool Lending Library Management System

#Tool Lending Library Management System is a modern inventory management application developed using Next.js, Supabase, and Tailwind CSS. The application enables staff to efficiently manage tools with complete CRUD functionality, track borrow and return records, monitor inventory through a dashboard, and organize tools by categories in a responsive and user-friendly interface.
